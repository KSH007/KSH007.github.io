# Contour Cosmetic Clinic Website

This is the static website for Contour Cosmetic Clinic, hosted on GitHub Pages.

## How to Host on GitHub Pages

1. Push this repository to GitHub.
2. Go to the repository settings.
3. Under "Pages," select the branch (e.g., `main`) and the root directory.
4. Save the settings, and your website will be live at `https://<your-username>.github.io/<repository-name>/`.
